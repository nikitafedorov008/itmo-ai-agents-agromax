# Contract v1 — shared by web, Flutter and API

API origin http://localhost:8787. All JSON camelCase. Errors {error,code,current?}. UUID ids generated by client or server. All /api except health and auth require Bearer token. Client must persist operationId across retries, never generate a new id for a retry. Dates ISO UTC.

- GET /api/health => {ok,storage}
- POST /api/auth/demo {} => Session (isolated new farm, not shared seed)
- POST /api/auth/login {email,password} => Session
- POST /api/auth/signup {email,password,name} => Session (or explicit email confirmation state)
- GET /api/bootstrap => Bootstrap (see packages/contracts/src/index.ts)
- POST /api/fields {operationId,confirmed:true,name,crop,areaHa,center,boundary} => Field; chief only, boundary=[] means point-only field without invented contour
- GET /api/photos/:id => private binary image, Bearer required
- GET /api/fields/:id/weather => Weather
- POST /api/photos multipart form field file => Photo; authenticated private retrieval URL; clients resolve relative URLs against API origin and send Bearer on retrieval
- POST /api/observations {operationId,...ObservationInput} => Observation
- POST /api/observations/:id/approve {operationId,version,confirmed:true,task?:{title,dueAt}} => {observation:Observation,task?:Task}; confirmation and expected version mandatory, idempotent transaction
- POST /api/tasks/:id/complete {operationId,version,confirmed:true,outcome} => Task
- POST /api/agent/chat {operationId,conversationId?,fieldId,message,provider,observationId?} => {conversation:Conversation,reply:AgentReply}; draft writes only through explicit observation endpoint; agent proposal cannot approve anything
- POST /api/sync {operations:SyncOperation[]} => {results:SyncResult[]}; each op atomic; approve payload contains id,version,confirmed,task; complete contains id,version,confirmed,outcome
- POST /api/notifications/:id/read {} => Notification

Observation approved with task atomically. Approved records immutable for MVP; revisit creates child observation via parentObservationId and completion outcome. Unknown/cross-farm ids 404. Conflicts 409 current record. Unconfigured model returns explicit 503, no fake AI fallback. Demo can use real models if configured, with per-session rate limits; never allows writes to real farms. Chat history persisted. Agent tools read-only (field history, tasks, weather, curated source search). Background runner server-side scheduled and idempotent, no public job trigger.

Frontend must use live API, no silent fake fallback. Default provider deepseek; selector mimo. Sources must be real referenced documents. Demo field polygons explicitly synthetic. UI and dates Russian. Brand logo source ../Agents/AGROMAX-HW3/assets/agromax-logo.svg; copy asset only, no old credentials/code.
